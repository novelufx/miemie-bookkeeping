# 咩咩的记账本 🎀

一个粉色可爱风格的手机端记账应用，为可爱的人打造的可爱账本。

**在线使用：https://miemie-bookkeeping.app.workbuddy.host/**

手机浏览器直接打开即可使用，无需安装、无需注册。

## 功能

### 记账
- 支出 / 收入 / 转账三类账目
- 自定义数字键盘，金额按「分」存储，无浮点误差
- 默认账户为微信（可在设置中改）
- 分类可自定义 emoji 或上传本地图片作图标
- 日期、备注、账户自由选择

### 快捷记账
- 首页 8 个快捷分类，可在「设置 → 快捷记账管理」中自选与排序
- 固定 8 个，不多不少

### 预算
- 月总预算 + 分类预算
- 首页与统计页实时进度条
- 记账后超支弹「温柔提醒」，不打断记账

### 统计
- 本月收入 / 支出 / 结余
- 支出分类占比环形图
- 每日收支趋势柱状图
- 账户余额一览

### 奶茶日历 🧋
- 独立的第 5 个 tab，与记账本数据互不干扰
- 月历视图，每天直接显示奶茶照片缩略图
- 本月杯数、品牌数、最爱品牌（喝得最多的）
- 每杯必传照片，可记录品牌（内置 10 个 + 自定义）、价格、糖度、冰度、备注

### 数据安全
- 主存储 + 3 份轮转备份，共 4 份副本
- 启动时自动挑选最完整的副本，主存储异常会自动恢复并提示
- 存储写入失败会明确告警，不再静默丢失
- 账本指纹：随时查看笔数、记录区间、距上次导出多久
- 换浏览器 / 换链接 = 另一个独立账本，App 会明确提示

### 导入导出
- 导出 JSON（可完整还原）/ CSV（Excel 可看）
- 导入备份（文件或粘贴内容）
- 粘贴文本导入历史账本，支持 `8.1 餐饮 35`、`7月15日 看病 200`、`2026/8/2 购物 99` 等格式
- 微信内自动走剪贴板，不被「可在浏览器打开此网页来下载文件」拦截
- 14 天未备份时首页出现静默提醒横幅

## 技术栈

- Vite + React 19 + TypeScript
- Tailwind CSS v4（CSS-first）
- framer-motion + lucide-react
- localStorage（账本数据）+ IndexedDB（图片）

## 本地开发

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 生产构建到 dist/
```

## 数据说明

- 账本数据存在浏览器 localStorage，图片存在 IndexedDB
- **不联网、不上云、无账号**，数据完全在本机
- 换设备需要先导出 JSON，再在新设备导入
- 清理浏览器缓存会清除数据，请定期导出备份到文件传输助手或网盘
